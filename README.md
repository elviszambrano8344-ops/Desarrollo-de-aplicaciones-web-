# Desarrollo de Aplicaciones Web

**Institución:** Universidad Técnica de Manabí (UTM)  
**Período académico:** 2026-2  
**Unidad:** 1

## Descripción

Este repositorio tiene como finalidad almacenar y organizar las actividades y los trabajos desarrollados durante la asignatura Desarrollo de Aplicaciones Web.

## Objetivo

Aplicar herramientas de control de versiones mediante GitHub, facilitando el almacenamiento, la organización y el seguimiento de los trabajos académicos realizados durante el período académico.

## Herramientas

- GitHub
- Git
- HTML
- CSS
- JavaScript

## Organización de los trabajos

En este repositorio se incorporarán progresivamente las actividades y los proyectos desarrollados durante la asignatura.
